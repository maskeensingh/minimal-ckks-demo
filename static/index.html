User side — your browser

Encrypt in your browser → calculate on the server → decrypt in your browser.

Browser: holds your numbers and secret key. Server terminal: receives encrypted objects and calculates. Open both windows side by side.

Use 1–16 comma-separated numbers per vector, between −1000 and 1000.

1. Encrypted inputs sent to the server

These three fields are the complete request. Your original numbers and secret key are not sent.

The text boxes contain full Base64-encoded SEAL objects. Base64 represents the encrypted bytes; it is not the encryption itself.

relin_keys — evaluation key sent for multiplication

2. Where the request and calculations execute

Browser console: client.mjs → encryptVector() encodes and encrypts. dashboard.mjs → form.onsubmit sends POST /calculate.

Server terminal: app.py → Handler.do_POST() receives the request and calls main.cpp → main(), where SEAL adds and multiplies ciphertexts.

Back in the browser: client.mjs → decryptVector() decrypts the returned ciphertexts.

Open Developer Tools → Console for actual browser calls, Network → calculate for the request and response, and the server Terminal for request receipt and completed SEAL operations. Messages contain no plaintext values or secret keys.
